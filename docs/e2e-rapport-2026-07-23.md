## Note config

Le fait que le dev local soit en `ESTALE_ECRITURE=reel` + `MAIL_SOURCE=graph` rend tout
test « clic » du cycle AG risqué en autonomie. Pour une passe write-through complète et
sûre : basculer temporairement `ESTALE_ECRITURE=dry` + neutraliser le mail, OU rester sur
SE999 (copro test) en pilotage humain pour les étapes d'envoi.
