# Où sont les gabarits métier

Les gabarits métier (Couverture AG, Convoc de base, Modèle ODJ, Fiche de renseignements eStale…) et les assets de marque (logo, favicon) vivent dans `data/gabarits/` et `data/assets/`.

Ces fichiers sont **non versionnés** (`data/` est git-ignoré) : ce sont des sources bureautiques lourdes, pas du code. Récupère-les auprès de l'équipe si ton clone ne les a pas.
